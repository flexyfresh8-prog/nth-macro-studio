NTH Macro Studio v2.0.0 — legitimate Windows automation for repetitive tasks: text expansion, form filling, UI testing, accessibility workflows. Recording uses low-level input hooks only while armed; playback uses SendInput, the standard user-session automation channel. No DLL injection, no memory access, no driver interposition, no network.
